新增「屏幕适配微调」：不同设备屏幕错位不用再等修，自己在面板里调——设置页 → 工具 →「屏幕适配微调」（桌面长按空白→装修模式、聊天设置→美化 也各有一个入口，三处开的是同一个面板）。面板顶部写着「正在调：桌面 / 聊天」，旁边两枚页签反色高亮的那一枚＝你现在正在调的页面，点另一枚就切过去看现场（面板自动收成小胶囊）。

滑杆按「哪一页生效」分三组：两个页面通用的位置轴（顶部 / 底部 / 页面高度 / 整体位移 / 左右安全边）、只影响桌面页的「桌面图标区」、只影响聊天与设置里正文文字的「文字大小」；哪一组标着「你正在这一页」，拖那一组就对了。

各轴各管一种错位：顶部内容被状态栏遮挡/离太远→「顶部」；底部导航栏被手势条裁掉/悬空→「底部」；页面底部留白/内容超出→「页面高度」；全屏时桌面图标按钮整体偏上→「桌面图标区」；整页偏上/偏下导致顶部或底部被遮挡→「整体位移」；曲面屏内容贴到屏幕弧边→「左右安全边」；正文文字太小→「文字大小」。

用法：拖动滑杆边看边调、当场生效，双击滑杆回默认 0；面板挡住画面时按住标题行上下拖即可把它挪开，点「收起」变一枚小胶囊（点一下展开、也能拖走让位）；「全部恢复默认」一键归零；每台设备各自调、互不影响、不随联系人走。

建议先跑 设置 → 信息诊断 →「屏幕适配诊断」 看差多少像素，再来填对应偏移；聊天页内还可配合聊天设置→美化 的「顶栏/底栏位置」滑杆单独微调。

3iPhone / iOS 使用与限制10
推荐用法：用 Safari 打开本站 → 底部「分享」→「添加到主屏幕」，之后从桌面图标打开使用。好处是：没有浏览器工具栏、能真全屏、也不跟一堆标签页抢内存。（注意这不是「装了就能多用内存」——存的东西多了，装在桌面上一样会被系统关掉重开。）更重要的是数据：不装到主屏幕，数据会被系统清掉。在 Safari 标签页里，Apple 会在连续 7 天没打开本站后自动清空它的全部本地数据（Safari 的隐私策略，网站躲不过）；添加到主屏幕后从桌面图标打开，就不受这条限制。注意主屏幕应用与 Safari 是两套独立存储：切过去之前先「导出数据」导一份完整备份，切过去后在桌面应用里「导入数据」恢复。
在 iPhone 上用 Edge / Chrome 的「添加到主屏幕」只会生成快捷方式，打开仍是带工具栏的浏览器页面，拿不到独立应用与全屏。
全屏：顶部系统状态栏（时间、电量、灵动岛）由系统控制，任何网页都无法隐藏；全屏开关只能隐藏应用内的模拟状态栏。真正无浏览器栏的独立应用，只有 Safari「添加到主屏幕」这一条路。部分旧版 iOS 浏览器（iOS 16.4 之前的 Safari）不支持网页全屏，点开会弹说明并回滚开关。
全屏会掉：切到后台再切回、或在浏览器里切换页面，全屏会失效，需手动重新打开。
方向：iOS 不支持屏幕方向锁定，不会自动锁竖屏，也不会纠正横屏（iPad 横屏是正常姿势，布局会自适应）。
声音：iOS 要求先与页面互动（点 / 滑一下）才允许播放有声内容，本站已在首次点击时自动解锁；如果全程没有任何操作，定时触发的来电铃声 / 消息音效可能不响。
系统通知：iPhone 浏览器内不支持系统通知；「离线消息提醒」（页面全部关闭后仍能收到 TA 的消息）只在安卓或电脑上的 Chrome / Edge 且添加到桌面后可用，iPhone / iPad 不支持。
导出 / 导入：从主屏幕打开时 iPhone 没有下载管理器，导出会走系统「分享」面板，请保存到「文件」App；导入时也会打开系统「文件」App 选备份文件。
语音：录音格式由系统决定，安卓录制的语音在 iPhone 上可能无法播放；iOS 的「文件」选择器会按类型过滤，导入字卡 / 语音等时个别文件可能灰显、选不中（系统限制）。
其他：iOS 没有振动反馈；Safari 会忽略网页设置的音量大小；字卡库 / 图片过多时更容易被系统回收内存、导致页面重新加载（用 设置 → 信息诊断 →「卡顿自检 · 一键优化」缓解）。

7常见问题16
数据突然没了 / 回到初始？多半是浏览器清理了本机存储。到 设置 → 通用 → 导入数据 恢复之前导出的备份。
更新版本会丢数据吗？不会。数据保存在本机，刷新 / 更新 / 关掉重开都不影响；只有清除浏览器数据、卸载、换机或系统回收存储才会丢（记得定期备份）。
没有声音 / 铃声不响？iOS 需先点一下页面才能出声（自动播放限制）；再确认 设置 → 聊天 → 音效设置 里已上传并开启。
上传的音乐播不了？通过网易云链接上传的 VIP / 付费歌曲无法播放（仅免费歌曲可播），歌单导入会自动移除这类歌曲；外链失效或有防盗链也会播放失败；网易云「分享短链」解析受解析服务影响，失败时先用浏览器打开那条链接、把地址栏里 music.163.com/song?id=数字 的完整链接或数字粘贴导入。本机上传的文件放不了则多半是加密格式或无损 m4a（ALAC 编码）——音乐 App 里下载 / 缓存的歌曲文件大多带加密，即使扩展名是 .mp3 / .flac / .m4a 也解不开，转成 mp3 再上传即可。
QQ音乐 / 酷狗 / B站等其他 App 的歌能导入吗？不能。音乐只支持三种来源：本机音频文件（上传音乐）、网易云歌曲 ID / 链接 / 歌单、音频文件直链。其他 App 的「分享」链接打开是网页而不是音频文件，导进来也放不出声；想在这里听，得先把音频文件存到手机里再用「上传音乐」添加。
图片传不上去 / 变模糊？超大图片上传时会被自动压缩，过大的会被拒绝（防止解码拖崩 iOS 页面），请换小一点的图。
收不到通知 / 后台弹窗？需允许系统通知权限并开启「后台保活」；「离线消息提醒」仅安卓 / 电脑上的 Chrome、Edge 且添加到桌面后可用。逐条对照（含 iPhone 为什么不行、开着却收不到的三种原因）见第 10 节「后台弹窗 · 怎么用（安卓 / 电脑）」。
开了后台保活后，其他声音变小或受影响？保活要在后台一直播放一段音频，手机同一时间通常只允许一路音频占用通道，所以会互相影响（别的 App 出声时保活也会被暂停再自动抢回）。这不是故障，是手机 / 浏览器的限制；不想受影响就到 设置 → 系统 关掉「后台保活」。若关掉后本页仍发出异常声音（电流声 / 嗡鸣）那才是 bug，请带机型 + 浏览器反馈。
全屏失效？切到后台或切换页面会退出全屏，手动重新打开即可；iPhone 顶部系统状态栏无法隐藏。

10后台弹窗 · 怎么用（安卓 / 电脑）15
它是什么：页面切到后台（锁屏、切到别的应用、回到桌面）时，TA 发来新消息就用系统通知弹一条横幅，不用一直守着聊天页；锁屏和下拉通知栏里也能看到内容。开关在 设置 → 系统 →「后台通知」，同一行右边的「测试」可一键体检。
它不是什么：不是真推送。消息是本机按概率随机生成的——「后台弹窗」只负责在页面处于后台时把它弹出来；不联网、不上传任何内容，也不代表对方真实在线。
前提 1 · 环境：用安卓或电脑上的 Chrome / Edge 打开，并且是 https:// 访问（本站 GitHub Pages 地址本身就是 HTTPS）。http:// 访问、或国产手机自带浏览器，多数拿不到通知能力。
前提 2 · 通知权限：地址栏左侧图标 → 网站设置 → 通知 → 允许。第一次打开「后台通知」开关时也会弹一次授权，点「允许」即可；若点了「拒绝」，开关会自动弹回关闭——这是防止「显示开着却实际无效」，不是坏了。如果你还没在弹窗里做出选择（弹窗挂着没点、或直接切走了），开关会保持开启并提示你去允许：这时通知还不会来，等你在「网站设置 → 通知」里允许后自动生效，不用再点第二次开关。
前提 3 · 后台保活要开着：打开「后台通知」会自动把「后台保活」一起打开。原因：TA 的消息由页面定时器产生，页面在后台被系统冻结就没消息可生成，也就无从弹起。若你后来手动关了保活，后台弹窗会静默失效（切回前台时会提示你）。
前提 4 · 系统层面允许通知：手机 系统设置 → 应用 → Chrome / Edge → 通知：允许。小米 / 红米（MIUI、HyperOS）等系统还要在「通知类别」里打开「在屏幕上方显示 / 悬浮通知」，否则通知只进下拉栏、不弹横幅。
前提 5 · 别限制后台：系统省电 / 后台管理里不要把该浏览器设成「限制后台运行」，否则页面会被系统杀掉，保活与通知都会断。建议设为「不受限制 / 允许后台运行」。
挂久了会截断/失效，怎么恢复：① 别的 App 刷视频、听歌会占用手机音频通道，把保活音频截停＝保活失效（回本页自动恢复）；② 挂后台太久，系统省电/内存策略会把页面冻结甚至丢弃重载（Edge「睡眠标签页」/Chrome「内存节省程序」约 30 分钟）。这两种情况后台弹窗都跟着停摆（手机/浏览器限制，不是网站坏了）。恢复：彻底关闭网页重新打开，再把「后台保活」「后台通知」开关重新打开；浏览器设置里把本站加入「永不睡眠 / 始终保持活动」名单可推迟失效。
怎么确认通了：点「后台通知」行右边的「测试」。它会先体检（通知权限 / 后台保活 / HTTPS /「主动发送」是否开着 / 本次后台通知的去重统计 / 联系人头像是否存在），再真发一条测试通知；卡在哪一环会直接写在结果里。
收不到 ① iPhone / iPad：iOS 的网页方式基本拿不到系统通知，本开关在 iPhone 上无效（不是网站坏了）。iPhone 请靠 设置 → 系统 →「桌面消息弹窗」：不在聊天页时新消息弹应用内横幅，切回应用时还会提示「你不在的时候收到 N 条新消息」。
收不到 ② 后台本来就没消息：TA 的聊天消息是按 回复设置 → 主动发送 的「间隔 + 概率」随机产生的。关掉「主动发送」、概率调成 0、或开着「免打扰」，后台就没有东西可弹（这与通知权限无关）。
收不到 ③ 被去重闸门拦了：刚切到后台的 15 秒内不发通知（多半是你刚看完的消息在补触发）；内容上也会去重——与最近 5 分钟聊过、最近 2 分钟弹过、或你刚在前台看过的同一条内容不再重复弹。TA 的字卡池重复率高，同一句被吞掉属正常，不是坏了。
和「离线消息提醒」的区别：两者完全独立、互不影响。后台弹窗＝页面还在后台运行时 TA 发消息弹通知（本开关 + 后台保活 + 通知权限）；离线消息提醒＝页面全部关掉后浏览器隔几小时唤醒一次、随机抽一条想念文案弹通知（仅安卓 / 电脑上的 Chrome、Edge 且添加到主屏幕）。哪个不开都不影响另一个。
代价：开着后台保活＝页面在后台持续运行，比较耗电、也可能发热，不需要时到 设置 → 系统 关掉；通知会在锁屏 / 通知栏显示消息内容，介意就在系统设置里关掉本应用的通知。
一句话路径：安卓或电脑上的 Chrome / Edge 打开本站 → 允许通知 → 设置 → 系统 打开「后台通知」（自动带上「后台保活」）→ 去系统设置给浏览器开通知、且不限制后台 → 点「测试」看到横幅即成功。
11手机卡顿怎么办（安卓 / iPhone）20
先记住两句话：iPhone——用 Safari 把本站加到桌面、从桌面图标打开，另外别让东西存太多（图片最占地方）；安卓——同样的情况好很多，但用久了也要清。
先说清楚两种「卡」：刚打开慢几秒是正常的——整个网站（所有页面、功能、字卡）装在一个文件里，约 5.5MB，第一次打开要整份读一遍，老手机慢几秒很正常，之后会快；用着一直卡、越用越卡，多半是手机里存的东西太多。
为什么东西多了就卡：这个网站没有服务器，所有东西都存在你自己手机上。图片存进去的时候会被转成一大段文字跟数据放在一起，所以占的地方比原图还大（大约多三分之一）。手机每次都要把这些文字读一遍——箱子越重，搬起来越慢。
哪一样占得最多，每台手机都不一样：聊天记录、字卡库、本地音乐、壁纸头像这类图片，都可能成为你这台手机上的第一名，怎么用就怎么占，跟别人不一样很正常。所以别照着别人的说法删自己的东西：先到 设置 → 工具 →「查看存储」，它会把每一类占了多少列出来，哪一项最大一眼就看见。
iPhone 和安卓不一样：iPhone 给一个网页的内存比电脑小得多，东西一多，系统就直接把页面关掉重开——切回来白一下、重新加载一下，东西不会丢，不是网站坏了。安卓内存大得多，一般到不了这一步；便宜的老手机更多是滑动掉帧、打开字卡库要等几秒。
「后台保活」开着也会更卡：页面在后台一直跑，费电、发热、掉帧都更明显。不用的时候到 设置 → 系统 关掉。
iPhone 第一条：别开「低电量模式」（安卓同理别开省电模式）：低电量模式会把整机帧率锁到一半（约 30fps），滑动、切页、打字全都会变卡——这是系统行为、不是网站坏了，关掉立刻恢复。路径：设置 → 电池 → 关掉「低电量模式」。如果「卡顿自检」报告里写着 ≈30fps 档，基本就是它。
还有几件事会加重卡顿：浏览器开了一大堆标签页、用了浏览器的「桌面版网站」模式、很久没彻底关掉重开过本站。
先实测：卡不卡不用靠感觉——「卡顿自检」：设置 → 信息诊断 →「卡顿自检」，点确定后正常去用所选时长（默认 2 分钟，可选 10 秒~5 分钟；10 秒档只能看「此刻顺不顺」），结束自动弹出实测报告：掉帧率与分级（流畅/轻度/中度/重度）、最慢一帧、掉帧集中在哪个页面、键盘弹出期占比、本地数据量画像，并给出对症建议；若查明是字卡库等数据过大，会指向旁边的「卡顿自检 · 一键优化」（不删数据）。说明：不支持长任务观测的内核（如 iOS WebKit）用帧间隔等效判定；切后台/锁屏的时间自动剔除、不会误报成卡顿；采样只在本机进行，不上传任何数据。
优化 ① 一键优化：设置 → 信息诊断 →「卡顿自检 · 一键优化」。它会把最占地方的东西提前读好，之后打开就不用等；不删任何数据。
优化 ② 看清谁占地方：设置 → 工具 →「查看存储」。「字卡库瘦身」把重复的图只留一份，能明显腾地方；顺手清一下诊断记录（清它不影响聊天 / 字卡 / 头像 / 音乐）。别搞混：「媒体池重建」不是用来腾地方的——那是聊天里图片显示不出来时用来找图的。本地音乐要到 桌面「音乐」→ ⚙ 设置 里清。
优化 ③ 把老图压小：设置 → 工具 →「压缩图片」。上传时本来就压过了，这里只处理以前存的老大图（会覆盖原图、不能撤）。它不压动图（GIF）和本来就小的图，所以表情包动图特别多的话，这一步省不出多少，得靠下一步手动删。
优化 ④ 删掉不用的字卡：字卡库 → 公用字卡 / 专属字卡，把不用的大图卡、语音卡删掉。「字卡使用状态自检」会把特别大的图片卡（单张超过 512KB）标出来。
优化 ⑤ 删旧的聊天记录：聊天页 → 聊天设置 → 数据，可以单独导出或删掉旧记录——先导出备份再删。聊天记录只进不出会一直涨；如果「查看存储」里最大的是它，这一步效果最明显。每个联系人桌面是分开的，要一个个看。
优化 ⑥ 清掉不听的音乐：桌面「音乐」→ ⚙ 设置 →「清理本地音频缓存」（「查看存储」里那行只是跳转入口）。
优化 ⑦ iPhone 用法：用 Safari「添加到主屏幕」，之后从桌面图标打开（没有浏览器工具栏，也不跟一堆标签页抢内存；用 Edge / Chrome 添加只会建快捷方式）。这不是「能多用内存」——存的东西多了，装在桌面上一样会被系统关掉重开。别同时开很多标签页；卡了就把应用完全划掉、重新打开一次。
优化 ⑧ 安卓用法：同样的东西，安卓一般不会被系统关掉页面，但数据还是会一直涨，长期用也要定期清（照 ①② 做）。另外别用「桌面版网站」模式，手机版更流畅；识别失手时用 设置 → 系统 →「手机布局（强制）」掰回来（也可用地址栏 ?mobile=1 / ?pc=1）。
优化 ⑨ 保持最新版：新版一直在做流畅度优化，顶部出现「检测到新版本」时点更新。
不是让你少存图：现在上传的字卡图会自动压到最长边 720px（表情包 480、头像 256），比以前的旧图小得多——正常存、正常用完全不用担心。真正拖慢手机的是两类老东西：以前没有压缩标准时存下的老图，和只进不出的历史数据（聊天记录、本地音乐、用不上的大图卡）。把这两类清掉就够了。要铺满屏幕的壁纸会保留大尺寸（最长边 2880px），但一台桌面也就一两张，不会堆起来。
千万别做：不要用「清除本地数据」来治卡顿——它不会修好任何东西，只会把数据全删光（聊天 / 字卡 / 头像 / 壁纸 / 音乐）。真要清，先到「导出数据」备份。
12设备与浏览器限制（看着像 bug，其实不是）19

13本站只是一个网页（前端网站）· 很多做不到是设备限制8
本站是一个网页，不是 App，也没有服务器：代码、字卡、图片、聊天记录全部只存在你自己手机里——没有账号、没有云端，作者收不到你的任何数据，也没法远程改动你这边的任何东西。所以网页能做什么，不是网站自己说了算，而是浏览器给不给这个能力；浏览器不给的，网站怎么写也做不到，这不是坏了。
网页没有「相册权限 / 存储权限」这回事：你点「上传图片」，弹出来的是浏览器的文件选择器或手机系统相册——是浏览器在弹，不是网站在翻你的相册。你不选、不点确定，网站一个文件都拿不到；选完也只有你挑中的那几个文件交给网页，其它照片网站看不到。
网站能提的建议只有两条：要什么类型（图片 / 音频）、能不能多选。浏览器可以听、也可以不听——所以「能不能一次选多张」最终由浏览器（或你所在 App 的内置浏览器）决定，网站这边只负责把选中的文件全部收下。
批量上传只能选一张、或点了完全没反应，多半是设备 / 浏览器的限制，不是你操作错了：先换 Chrome / Edge 再试一次；在微信 / QQ / 钉钉里打开的要先点右上角「在浏览器打开」；iPhone 用 Safari，或把本站「添加到主屏幕」后从图标进。换过仍然只能选一张，那就是这台设备 / 这个浏览器本身不支持多选，不是网站的 bug。

网页做不到的事还有一大串，都不是网站偷懒：系统通知、隐藏手机系统状态栏、振动、调音量、锁定屏幕方向、下载 / 分享面板、跨系统的录音格式……这些接口浏览器根本没给网页，任何网站都做不到。逐条对照见上一节（第 12 节「设备与浏览器限制」）。

语料来自四类字卡——造句就是在「自定义字卡＋默认聊天字卡＋词典」这三处字卡里选的（词典＝字卡库→词典，和默认聊天字卡同属系统预设），对应下方三个「语料·」开关，细分四类：
· ①【自定义字卡·公用字卡】＋ ②【自定义字卡·专属字卡】——由「语料·自定义字卡」一个开关管两个作用域（公用全桌面共享、专属只在本联系人桌面）；字卡库→可自定义字卡 里两个作用域各自的【分组停用】都生效，改/删字卡实时跟新，抽语料时会跳过【其他互动功能字卡】类（鱼塘/吃喝/经期/花园/此间/房间/存钱罐/漂流瓶/互动回应/音乐/这里造的句子本身…）；
· ③【系统预设·默认聊天字卡】——由「语料·默认聊天字卡」开关控制，取 字卡库→系统预设→默认聊天字卡 的四大基础分类（主字卡 / 颜文字 / emoji / 拍一拍）；颜文字与 emoji 基本不含 4 个以上汉字，实际不会成为源句，真正参与的是主字卡与拍一拍。该分类的开关（主字卡/颜文字/emoji/拍一拍）与逐张关闭都生效；
· ④【系统预设·词典】——由「语料·词典」开关控制，取 字卡库→词典 的全部语录（词库里的 2~3 字词只用于切词、不作为源句）；词典的逐张关闭生效（关掉的语录不再被用）。
· 二级密码锁锁定时：系统预设（③默认聊天字卡 / ④词典）不参与，①②自建字卡照常。
权重怎么算：三个「权重」＝抽语料时各源的中签占比，按权重归一化（默认 50/25/25，不必凑够 100）；某个源权重调 0 或开关关掉＝该源不参与，三源全关＝不触发造句。
造句手法（上方数字 0/1/2，效果举例，源句「今天也要好好爱自己，晚安哦」）：
· 0 语气词式：截掉一个词补个语气词 →「今天也要好好想你了」，或句尾加语气字 →「…晚安哦呀」，也可能词间加逗号/空格、删句尾字；
· 1 撤回式：像撤回消息一样把后半句撤回，留下的前缀就是新句子 →「今天也要好好爱自己」；
· 2 换字卡内容式：截掉一个词、从上面的语料里挑一个词补上 →「今天也要好好看日落」。
「混合模式」（#414，#513 起默认开）：开启后每次造句先在 0/1/2 三种手法里随机掷一个再出招，三种模式交替出现，上方「造句手法」的固定选择暂不生效；关闭即恢复单一手法（默认撤回式）。
句尾标点（#953）：造出的句子默认按「可用标点」里的候选随机补一个句尾标点（默认 。 / ~ / ！ / ……，句号权重最高）；某个句子本身结尾已经有标点就不重复补。「可用标点」框里用空格分隔多个候选（也可写 | 分隔），单个候选可以多字（如 ……）；留空＝用默认池。把「句尾标点」开关关掉＝不补任何标点，出句保持原样（如撤回式截断后的裸句）。
造出来的句子去哪了：自动存进 字卡库→可自定义字卡→梦角自由造句（可查看/删除）。存哪个库由上方「存公用库概率」决定：0＝全进专属字卡、100＝全进公用字卡、其余按概率分流（默认 80＝80% 公用 / 20% 专属）；单联系人也照此生效（想全留本桌面就把概率设 0）。这些句子只作为 TA 的回复展示，不会再被拿去当语料（避免自我循环）。

【来电概率是怎么触发的】有 3 类「机会」，每来一次机会就单独掷一次骰子，命中就打来电话：① TA 每回复你一条消息，掷一次；② TA 每次主动给你发消息，掷一次；③ 应用开着时，后台每 1~2 分钟也会掷一次兜底。两次来电之间至少间隔 5 分钟，设 0 则从不主动来电。
【为什么设得不高却感觉来得挺勤】概率是「每次机会」单独算的，不是「每天总共」的概率——你聊天越勤，机会就越多，累积起来自然来电频繁。例如设 15%：和 TA 聊 20 句就有约 20 次掷骰机会，来电概率本身没坏，是机会次数多。想让来电变少，直接把数值调小即可，效果大约成比例：调小 10 倍，来电也约少 10 倍。
【嫌多又不想设 0】点数值框直接输入小数（如 0.05），不用狂按 +/−。来电概率支持 0.01 粒度，最低可设 0.01（0.05、0.1 等 0.0几 的数值都可以）——设 0.01 时平均每 100 次机会才来电 1 次，基本只是偶尔响一次。
【接听 / 忙线 / 拒接概率】你打给 TA 时用：按「忙线 → 拒接 → 接听」顺序判定，先命中哪个就是哪种结果；三项都没命中就是「未接通」。默认 15 / 15 / 70 恰好占满 100，不会有未接通；想偶尔出现未接通，把三项合计调到 100 以下。
【通话中挂断概率】接通满 3 分钟保护期后，每 60 秒掷一次，命中对方就主动挂断，通话越久累计越容易被挂。支持 0.01 粒度，最低可设 0.01；设 0（或开下方「禁止联系人挂断电话」）＝对方永不主动挂断。
【改数值】点数值框直接输入（手机会弹数字键盘），或按 +/− 微调；改完立即保存生效。以上概率均按联系人各自保存，互不影响。
